# 出典関連性ゲートの許可リスト

`scripts/check-source-relevancy.mjs` は型番トークンと出典 URL の照合で
「別商品出典」事故を検出する。公式ページ自体は正しいが slug / path / query に
型番トークンを含まない URL は、ゲートを緩めず以下の表に `id` × `url` で登録して
除外する（スクリプトがこの表をパースして適用する。行を削除すれば即時にゲートへ復帰する）。

## 運用ルール

- 1 行 = 1 例外。`id`（記事ID）× `url`（出典URLそのまま）単位で照合する。
- 登録条件: 公式ページの本文・仕様表で比較対象の型番を確認済みであること。理由欄に確認日と根拠を必ず書く。
- 型番入りの公式 URL が後から見つかった場合は、許可行の追加ではなく URL 自体の差し替えを優先する。
