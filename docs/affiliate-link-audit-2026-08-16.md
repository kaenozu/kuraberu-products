# 楽天アフィリエイトリンク監査（2026-08-16）

## 結論

- 記事ページの購入CTAを全件確認した。
- 通常の `search.rakuten.co.jp` URLが残っていたKX-HC705と、作成中だったEH-NA9M / EH-NA7Mを、`hb.afl.rakuten.co.jp`へ差し替えた。
- 既存記事の `a.r10.to` および `hb.afl.rakuten.co.jp` は、ソース上の楽天アフィリエイト導線として確認した。
- 今後は、通常の楽天検索URLを購入CTAに使えないよう、レンダリング検査でエラーにする。

## 運用ルール

1. 記事作成時に、楽天アフィリエイトへログインした状態で商品ごとのリンクを生成する。
2. 生成URLを記事の全購入CTAへ設定する。
3. `purchaseLinksCheckedAt` と `purchaseLinkStatus: "verified"` を更新する。
4. `pnpm verify` と本番前プレビューで確認してからPRを提出する。
5. アフィリエイトURLを確認できない記事は公開対象にしない。

`a.r10.to`は短縮リンクのため、リンク先の商品・価格・在庫は遷移先で確認する。
